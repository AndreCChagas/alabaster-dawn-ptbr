# Alabaster Dawn - Tradução PT-BR

Tradução de fã do **Alabaster Dawn** para o português do Brasil, feita direto do inglês: menus, opções, itens, enciclopédia, diário, Sonho de Somu e todos os diálogos (100% dos textos).

📖 **Guia na Steam:** [Alabaster Dawn tradução não Oficial - pt_BR](https://steamcommunity.com/sharedfiles/filedetails/?id=3735223577)

## ⬇️ Download

Baixe o arquivo `AlabasterDawn-PTBR-<versão>.zip` da versão mais recente em **[Releases](https://github.com/AndreCChagas/alabaster-dawn-ptbr/releases/latest)**.

Não precisa de nenhum programa extra: o jogo reconhece a tradução sozinho.

## 🛠️ Instalação

1. Na Steam: botão direito em **Alabaster Dawn** → **Gerenciar** → **Ver arquivos locais**.
2. Copie a pasta `terra` do ZIP para essa pasta (onde está `alabaster_dawn.exe`) e substitua os arquivos se o Windows perguntar.
3. Abra o jogo e escolha **Options → Language → Português (Brasil)**.
4. Feche e abra o jogo de novo.

> Deixe a opção **Tradução pela Internet** (*Live Localization*) desligada.

**Atualizando de uma versão anterior:** é só copiar a pasta `terra` do ZIP novo por cima.

**Desinstalar:** apague a pasta `terra\data\locale\pt_BR` dentro da pasta do jogo.

Quando o jogo recebe atualização, textos novos podem aparecer em inglês até sair uma nova versão da tradução.
